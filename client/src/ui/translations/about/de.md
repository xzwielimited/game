# Description
Iron Fleet ist ein online Multiplayer Schiff Combat Spiel, ursprünglich erstellt von Softbear Studios und nun als unabhängige Community-Edition gepflegt. Das ziel ist es, dein Schiff, mit dem sammeln von Kisten und dem sinkenn von anderen Schiffen, upzuleveln. Es gibt [# Schiffe](/ships/) und 9 Waffen die du wählen kannst. Und das verteilt auf [# immer mächtiger werdende levels](/levels/)
