# Description
Iron Fleet is an open-source online multiplayer naval combat game, originally developed by Softbear Studios and now maintained as an independent community edition. The goal is to level up your ship by collecting crates and sinking other ships. There are [# boats](/ships/) and [#](weapons) weapon types to choose from, spread over [# progressively more powerful levels](/levels/).

To learn more about the game, visit the [help page](/help/).
